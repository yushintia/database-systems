# Lab 01 Problems — Introduction & the Spreadsheet Problem

Public restatement of Lab 01's hands-on activity. Full lab page:
`book/src/labs/lab01-intro-and-spreadsheet.md`. Seed file:
`book/src/labs/files/lab01/registrations.csv`.

No worksheet or quiz this week — Week 1 is the orientation variant.
This is the only graded item for Week 1.

## Task 1: Find the Name Inconsistency

One real student appears in `registrations.csv` under three different
spellings of the same name.

1. Find all three spellings, and the row number(s) each appears in.
2. State one thing a name-only search would miss.

## Task 2: Simulate the Deletion Anomaly

Find the one course with only a single enrollment row.

1. Identify the row (row number, student, course).
2. State what information disappears if that row is deleted, besides
   the enrollment fact itself.
3. Explain why deleting one fact deletes unrelated facts too.

## Task 3: Role-Play the Concurrent-Edit Race

With a partner: both open the same starting data, make simultaneous
conflicting edits to the same student's row, and observe which change
survives.

1. State whose change survived and whose vanished.
2. Explain how either partner would have noticed, without today's
   exercise.
