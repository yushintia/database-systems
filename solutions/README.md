## Conventions

Every SQL solution follows `book/src/appendix/sql-style-guide.md`:
UPPERCASE SQL keywords, PascalCase singular table names matching the
case study (`Student`, `Course`, `Instructor`, `Section`,
`Enrollment`), snake_case columns, named constraints, a mandatory file
header comment, and a clean run against MySQL 8.x with no errors.
Every seed and answer-key `.sql` file targets the single shared
database name `registration_db`.
